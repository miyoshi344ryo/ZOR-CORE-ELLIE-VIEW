# ZOR-CORE Public Manifest

This repository is a bounded public view of selected ZOR-CORE information.
It is not the ZOR-CORE Canonical Core.

## Included
- Architecture overview
- Validation boundary
- Provenance policy
- Selected public status

## Excluded
- Secrets and credentials
- Personal information
- Private research history
- Unpublished raw media
- Uncleared external archives
- Canonical replacement material

The authoritative Source of Truth remains the project-managed R4.5-CANONICAL architecture files.
